# Статус Медики

8 ноября 2026: первая локальная версия реализована и запущена: **http://medika.localhost**.

Главная уплотнена для телефона: одна строка шапки, затем название, доза и время крупно. По закрытым строкам имена получателей указаны мелко; подробности открываются нажатием. Профили и исходные документы свёрнуты. Имя исправлено на «Алиса» в рабочей базе с сохранением ID и связей. Регрессионный canary проверяет ширины 320/360/390/768/1024/1470: шапка телефона ≤56 px, первое лекарство начинается не ниже 95 px, строка ≤100 px, четвёртая начинается выше 500 px. Отдельно проверены персональное подтверждение и компактный фактический приём. Данные выписок остаются неподтверждёнными до сверки.

Доступ с домашнего Wi-Fi добавлен: **http://192.168.0.38** и **http://macbook-air-5.local**, без порта и отдельного DNS. Страница/ресурсы, сессия и API проверены с Mac через его Wi-Fi IP; Bonjour-адрес также отвечает. Физический iPad пока не проверен. Caddy допускает только текущую домашнюю подсеть и loopback, backend остаётся на loopback, Host/Origin проверяются. Отдельных аккаунтов и TLS нет: режим предназначен для доверенной домашней сети. Проверки: `reports/lan-access.json`, `reports/proxy-canary.json`; причина и условия — `reports/ipad-lan.md`.

Порт скрыт существующим системным Caddy: 80 → внутренний 4382. Маршрут сохранён в `/opt/homebrew/etc/Caddyfile`; другие домены сохранены. Приложение принимает правильный Host без порта и сохраняет проверку Origin. Сквозной proxy-canary проверяет браузер, относительные ресурсы, сессию, API и перезапуск на синтетических данных. Подтверждение живого адреса — `reports/local-domain.json`.

- Диспетчер: проект `5bc913d8-ae85-470b-a91e-251a2a589364`, сервис `web`, lifecycle `active`, runtime `running`, HTTP readiness и runtime.health — PASS. Watch включён для исходников приложения. Данные исключены из watch.
- Работают профили людей с возрастом на указанную дату, назначения, ежедневные часы и выбранные дни недели, точные интервалы, разовые назначения и приём по необходимости, журнал факта, исправление отметок с историей и архив назначений. Есть доза «в каждую ноздрю» и помощник длительности в днях, неделях и календарных месяцах с явной включительной границей.
- Локальный Apple Vision распознаёт русский/английский; проверены PNG, JPEG и WebP. Оригиналы и распознанные строки сохраняются. Перенос в расписание требует сверки.
- Есть персональные дозы и условия из назначений в справочнике, проверка предполагаемого препарата, автоматические предупреждения по текущей схеме, совпадение с указанной аллергией и повторение вещества.
- Резервная копия содержит данные, историю и изображения; восстановление добавляет отсутствующие записи без перезаписи конфликтующих версий. Есть CSV журнала.
- Главная — общая семейная доска: приёмы по времени для всех, текущие курсы каждого человека, дозы, цель «зачем», условия, сроки и день курса. Неподтверждённые строки показаны в общей таблице. Отметка, редактирование и оригинал доступны без перехода. Папа и мама — отдельные профили; отображаемое имя ребёнка — «Алиса», исходный ID и связи документов сохранены.
- 12 unit/API-тестов и 12 групп сквозного canary — PASS. Общая доска проверена на 1470/1024/390 px, включая четыре профиля, пустые карточки, действующие/будущие курсы, PRN, черновики и возврат из фильтра одного человека. Скриншоты в reports/ содержат только синтетические данные.
- По присланным материалам созданы два детских профиля и сохранены три оригинальные фотографии в каждом профиле. Возраст — со слов пользователя, без выдуманной даты рождения. Бумаги врача отделены от домашней доски; текст сверки, сырой OCR и неясности доступны в «Выписках». Перед импортом сохранена закрытая резервная копия. Повтор импорта не дублирует документы.
- Реальные препараты и отметки не активированы: документы содержат неоднозначности даты начала, кратности и отдельных доз. Многострочные предложения распознаются как черновики; домашняя доска автоматически не создаёт ни назначения, ни факт приёма.

Ограничения: 8 веществ / 4 справочных правила не заменяют полноценную медицинскую базу; страна обращения лекарств ещё не выбрана. Детские дозы и все противопоказания не рассчитываются автоматически. Уведомления работают только при открытом приложении и разрешении браузера. Реальные фотографии рассмотрены: печать распознаётся заметно лучше почерка, почерк требует ручной сверки. Относительный интервал 10–15 минут и этапы курса сохраняются в исходном тексте/условиях; автоматического запуска следующего средства после фактического приёма предыдущего пока нет. PDF/HEIC в этой версии не принимаются.

Автоматическое открытие страницы через Computer Use недоступно: локальный браузер отключён в настройках Work. URL проверен через DNS/HTTP; интерфейс — в headless Chromium.
