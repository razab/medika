# Статус Медики

8 ноября 2026: запущен новый интерфейс «пациент и история».

- Четыре пациента, личная компактная лента, общая кнопка «Событие голосом», без предварительного выбора человека и клавиатуры.
- Локальный Whisper ru/en: микрофон → отправка после паузы → определение человека/события/времени → запись и короткое подтверждение с отменой. Уточнение только для неясной фразы. Без отправки аудио наружу.
- Поддержаны «две минуты назад», «минуту назад», «полчаса назад», «получил таблетку/свечку»; позывы к рвоте учитываются отдельно от рвоты.
- Лекарства, дозы, время, температура, симптомы и процедуры сохраняются в истории; исходная фраза и контекст предписания связаны с записью.
- «Врач» свёрнут: профилактика/острая фаза, назначения, исходные выписки, локальный OCR и ручная сверка.
- Прежние данные сохранены. Копии v4; восстановление v1–v4 без дублей и потери старых записей.
- HTTP: http://macbook-air-5.local и http://192.168.0.38. HTTPS: https://macbook-air-5.local и https://192.168.0.38. Портов в адресе нет.
- На iPad для микрофона один раз установить и доверить Medika Local Root: http://macbook-air-5.local/medika-ca.cer. Текстовый ввод работает по HTTP.
- Предыдущая сложная версия: Git-ветка `archive/before-patient-first`, коммит `3a4e5a5`.

Проверены 22 unit/API-теста, сквозной ввод с настоящим локальным распознаванием синтетической речи, OCR, отмена, перезапуск, восстановление, ширины 320/390/768/1024/1470 и опубликованный HTTPS. Сценарии выполнялись в headless Chromium с временной базой, без реальных медицинских данных. Физический iPad и его микрофон не проверены. Голосовой диалог с уточнениями — фаза 2. Точность сложной свободной речи требует проверки перед сохранением.
