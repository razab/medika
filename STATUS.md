# Статус Медики

8 ноября 2026: первая локальная версия реализована и запущена: **http://medika.localhost:4382**.

- Диспетчер: проект `5bc913d8-ae85-470b-a91e-251a2a589364`, сервис `web`, lifecycle `active`, runtime `running`, HTTP readiness и runtime.health — PASS. Watch включён для исходников приложения. Данные исключены из watch.
- Работают профили людей, назначения, ежедневные часы, точные интервалы, разовые назначения и приём по необходимости, журнал факта, исправление отметок с историей и архив назначений.
- Локальный Apple Vision распознаёт русский/английский; проверены PNG, JPEG и WebP. Оригиналы и распознанные строки сохраняются. Перенос в расписание требует сверки.
- Есть персональные дозы и условия из назначений в справочнике, проверка предполагаемого препарата, автоматические предупреждения по текущей схеме, совпадение с указанной аллергией и повторение вещества.
- Резервная копия содержит данные, историю и изображения; восстановление добавляет отсутствующие записи без перезаписи конфликтующих версий. Есть CSV журнала.
- 8 unit/API-тестов и 10 групп сквозного canary — PASS. Проверены все разделы на 390 px; desktop и mobile скриншоты находятся в reports/.
- Рабочая база при передаче пуста: тестовые профили и назначения создавались только во временных каталогах.

Ограничения: 8 веществ / 4 справочных правила не заменяют полноценную медицинскую базу; страна обращения лекарств ещё не выбрана. Детские дозы и все противопоказания не рассчитываются автоматически. Уведомления работают только при открытом приложении и разрешении браузера. Реальные выписки пользователя и рукописные назначения ещё не проверялись. PDF/HEIC в этой версии не принимаются.

Автоматическое открытие страницы через Computer Use недоступно: локальный браузер отключён в настройках Work. URL проверен через DNS/HTTP; интерфейс — в headless Chromium.
