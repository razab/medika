# Медика

Локальный семейный журнал назначений, приёмов лекарств и событий. Основное приложение: **http://192.168.0.38/**, на Mac также **http://medika.localhost**, без порта.

В обзоре — люди, лекарства с группой и дозой, слоты еды или конкретные часы, отметки и история. Добавление препарата по фото находится в каталоге; добавление человеку и перенос существующего приёма выполняются в рабочем расписании. Связанный таймер не блокирует запись после истечения интервала.

## Документация

- [USER-FLOWS.md](USER-FLOWS.md) — 28 пошаговых пользовательских сценариев: входы, варианты, результат, ошибки, состояние реализации и проверки.
- [DESIGN-RULES.md](design-study/DESIGN-RULES.md) — какие данные и действия видны на каждой поверхности, частота действий, размеры зон и касания.
- [PROJECT.md](PROJECT.md) — использование, архитектура, данные, ограничения и управление сервисом.
- [STATUS.md](STATUS.md) — актуальное состояние и незавершённые части.
- [PROJECT-PLAN.md](PROJECT-PLAN.md) и [BRIEF.md](design-study/BRIEF.md) — исходный план и история итераций; текущие рабочие пути описаны в USER-FLOWS.md.

## Рабочие экраны и стенды

Главный экран — `/` и `/family`; препараты — `/medicines`; рабочий разбор выписки — `/prescriptions/import`; прежние подробные инструменты — `/manage`.

Тестовые журналы отделены от семьи: `/playground` — OCR и варианты интерфейса, `/voice-lab` — сравнение распознавания, `/design-study/a1` — изолированное демо дизайна. Наличие тестового сценария не заменяет рабочий пользовательский путь.

Голос на телефоне требует доверенного локального HTTPS: **https://192.168.0.38/** или **https://macbook-air-5.local/**. Просмотр по HTTP не требует доступа к микрофону. Mac должен работать в той же сети.

Справочные проверки неполны: неизвестные ограничения требуют сверки, дозы и смеси не придумываются. Автотесты из корня: `npm --prefix site test`; сквозные проверки — в `site/scripts/`. Их связь с пользовательскими сценариями приведена в USER-FLOWS.md. В отчётах используются только синтетические данные; клинические материалы и `site/data/` не коммитятся.

Рабочим сервисом `web` управляет Local Projects Dashboard. Исходная версия сохранена в `archive/before-ocr-playground` (`e26e1be`); текущая работа — `work/ocr-playground`. Git remote не настроен.
