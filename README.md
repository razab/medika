# Медика

Локальные назначения и события семьи. Новый OCR-стенд и шесть работающих вариантов интерфейса: **http://192.168.0.38/playground**.

«Сложный пример» распознаёт настоящую синтетическую картинку. Можно загрузить свою выписку, исправить OCR, выбрать пациентов, один раз настроить доступные слоты и получить общий план. Фазы и альтернативы сохраняются; часы каждому лекарству вручную не нужны. Вес, возраст, форма, концентрация и разовая доза — отдельные данные.

Кнопки **1–6** — по слотам, по людям, лента, таблица, чек-лист, ближайший приём. **⛶ / ⚙** — чистый пользовательский экран и настройки стенда. Работают «Принято», отмена, начало/завершение ингаляции, история, фото упаковки и редактирование. Тестовый журнал отделён от семьи; синтетический пример в клинический журнал не переносится.

Основное приложение: http://192.168.0.38, на Mac — http://medika.localhost. На основном расписании есть **✓ «Принято сейчас»**. Реальный групповой импорт — «Врач → Разобрать выписку». Голосовой стенд сохранён: https://192.168.0.38/voice-lab; микрофону нужен доверенный локальный HTTPS.

Справочные проверки неполны: возраст берётся из явной инструкции/этикетки, дозы и смеси не придумываются. Неопределённости требуют сверки. [Использование, архитектура и ограничения](PROJECT.md).

Код до переделки: `e26e1be`, ветка `archive/before-ocr-playground`. Новая работа: `work/ocr-playground`. Git remote не настроен.

Проверки из корня: `npm --prefix site test`; Playwright-сценарии в `site/scripts/`. В отчётах — только синтетика. Клинические документы, голос и `site/data/` не коммитятся. Рабочий сервис запускается только через Local Projects Dashboard, сервис `web`.
