# Медика

Локальное приложение для назначений и приёма лекарств нескольких людей.

**Открыть:** http://medika.localhost:4382 · **Диспетчер:** http://127.0.0.1:4317/project?id=5bc913d8-ae85-470b-a91e-251a2a589364

Описание и эксплуатация: [PROJECT.md](PROJECT.md). Готовые возможности и ограничения: [STATUS.md](STATUS.md). Проверки: [reports/test-report.md](reports/test-report.md).

## Первое использование

1. Добавить человека.
2. Создать назначение вручную или загрузить выписку в PNG, JPEG, WebP. Текст также можно вставить вручную.
3. Сверить распознанные поля с оригиналом, указать даты и часы, подтвердить перенос.
4. В расписании отмечать фактический приём. В справочнике проверять предполагаемый препарат с назначениями выбранного человека.

Доза из назначения и общая справочная информация разделены. Проверка совместимости сейчас ограничена 8 веществами / 4 правилами и всегда обозначается как неполная. Расчёт детских доз не предусмотрен.

Загруженные реальные фотографии доступны в [Выписках](http://medika.localhost:4382/#documents). В каждом профиле сохранены общие бумаги врача и доска семьи, исходный OCR и заметки сверки. Новые варианты: выбранные дни недели, доза в каждую ноздрю и помощник календарной длительности. Из домашней доски назначения и фактические приёмы автоматически не создаются.

## Разработка и проверки

Код находится в `site/`, runtime npm-зависимостей нет. Нужны Node.js 24+ и macOS с Apple Vision / Swift compiler. OCR уже собран на этом Mac; для чистой копии: `npm run ocr:build` из `site/`.

`npm test` запускает unit/API-проверки во временной SQLite-базе. Сквозной тест: `node scripts/canary.mjs`; он требует Playwright. На текущем Mac существующая установка переиспользуется через переменную `PLAYWRIGHT_MODULE=/Users/dcor/projects/my/analysis/plan/kickstart/07-local-interest-radar/site/node_modules/playwright/index.mjs`. Тест сам запускает временный сервер на 14382, создаёт синтетические изображения, проверяет перезапуск и восстановление копии и удаляет тестовую базу. Рабочий сервис 4382 не изменяется. API-тест использует 14383.

Для запуска рабочего сервиса использовать Local Projects Dashboard API, проект по пути этого каталога, сервис `web`. Отдельные npm/nohup/PTY-экземпляры не запускать. Медицинские данные в `site/data/` исключены из Git, в отчётах — только синтетические примеры.
