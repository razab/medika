# Компактный телефонный экран

По обратной связи пользователя предыдущая версия всё ещё тратила слишком много места на шапку, пояснения и действия. Вместо открытых карточек введены закрытые строки: крупные название, доза, время; имена получателей — мелко. Детали, источник, длительность и уточнение раскрываются по нажатию. Семья и курсы свёрнуты. Неподтверждённые строки обозначены одной короткой строкой статуса.

Отображаемое имя в рабочей базе исправлено на «Алиса» через API с сохранением ID и связей. Перед изменением сохранена закрытая полная копия. Возраст, назначения и факты не изменялись.

В dashboard-canary добавлены реальные границы плотности на 320/360/390 px: высота шапки ≤56, начало первого лекарства ≤95, высота строки ≤100, четвёртая строка начинается выше 500. Проверяются также планшет, десктоп, раскрытие и подтверждение схемы отдельно для Алисы, отметка, перезапуск и копия. Опубликованные ресурсы проверены через Wi-Fi URL с временным синтетическим API.

Первый полный прогон нашёл горизонтальный выход у отмеченного приёма с длинным названием: прежняя широкая кнопка исправления и наследуемый display:block у названия нарушали компактную строку. Проблемный вариант остановлен, ряд переведён в grid с ограниченной колонкой действий, исправление заменено компактной кнопкой с доступным именем. Малый canary после изменения проверяет отмеченную строку без горизонтального скролла и с высотой ≤100. Повторный полный прогон подтвердил исправление этого варианта.

Свёрнутые блоки больше не читаются тестами через innerText: это не проверка их содержимого. Для сохранности данных используется textContent, для видимых названий/доз/времени — boundingBox и скриншоты. Все иллюстрации и браузерные записи синтетические. Физический телефон не автоматизировался.
