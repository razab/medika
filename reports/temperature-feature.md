# Измерения температуры

Реализованы отдельная таблица измерений с привязкой к человеку, POST /api/temperatures, отмена с версией/причиной и сохранением исходной записи, кнопка «＋°C», форма из трёх полей, компактные последние значения на главной, личная история в окне и общий журнал с фильтром. Измерения не создают назначений или фактов приёма препарата. Последнее значение определяется фактическим временем, не временем ввода; отменённые записи не участвуют. Хранятся °C, абсолютное время и часовой пояс устройства. При другой выбранной дате показывается дата измерения, чтобы время не воспринималось как относящееся к выбранному дню.

Копия экспортируется в формате v2 с обязательным разделом temperatures, чтобы прежний импортёр v1 не принял её с молчаливой потерей измерений. Новый импортёр принимает v1 и v2. Импорт старой копии не удаляет записи; конфликт версии отклоняет восстановление до записи данных. Миграция SQLite аддитивная; перед рабочим перезапуском сохранена закрытая копия site/data/before-temperatures.json.

Малый temperature-canary проверяет весь путь: три поля → запятая → последнее значение → ввод старого измерения → второй человек → отмена с историей → фильтр → перезапуск → пустая база и восстановление копии без дублей. Проверены 320/390/768/1024 px и совместное отображение с лекарствами. Затем пройдены 14 unit/API-тестов, основной canary (12 групп), отдельный dashboard-canary и proxy-canary. Все данные браузерных тестов синтетические; реальные медицинские факты в рабочую базу не добавлялись.

В начальном canary выявлены ошибки тестовой синхронизации: проверка количества строк выполнялась до завершения фильтра, а переход только по hash не перезагружал приложение после рестарта. В тесте теперь ожидается выбранный фильтр, затем выполняется явная перезагрузка. Исправленный малый прогон прошёл до запуска полных проверок. Команды скриптов выполняются от корня проекта как node site/scripts/...; неверный рабочий каталог ранее остановил один запуск до начала теста.

Температуре не присваиваются клинические категории и рекомендации. Снимки temperature-form.png, temperature-phone.png, temperature-history.png содержат только синтетические измерения. Физический телефон/iPad не автоматизировался.
